# JOBSHIELD – Job Market Fraud Intelligence System

## 📌 Project Overview
JOBSHIELD is a data analytics project designed to analyze fake job postings and identify patterns associated with fraudulent recruitment activities. It helps users understand job market fraud through visual analytics and interactive dashboards.

The project uses data visualization to highlight fraudulent job postings across different industries and employment types, making it easier to understand potential recruitment fraud patterns.

## 🎯 Objectives
- Analyze fake and genuine job postings.
- Identify fraudulent job posting patterns.
- Compare genuine and fraudulent job listings.
- Visualize fraud distribution across industries.
- Analyze fraud based on employment types.
- Provide insights through an interactive Tableau dashboard.

## 📊 Dataset Overview
The project uses a fake job postings dataset.

| Metric | Count |
|---|---:|
| Total Job Postings | 17,880 |
| Genuine Job Postings | 17,014 |
| Fraudulent Job Postings | 866 |
| Fraud Rate | 4.84% |

## 📈 Dashboard Features
- **Total Jobs KPI** – Displays the total number of job postings analyzed.
- **Fraud Jobs KPI** – Shows the number of fraudulent job postings.
- **Genuine Jobs KPI** – Shows the number of legitimate job postings.
- **Fraud Rate KPI** – Displays the percentage of fraudulent postings.
- **Industry-wise Fraud Analysis** – Visualizes fraudulent job postings across industries.
- **Employment Type Analysis** – Analyzes fraudulent job postings based on employment types.

## ⚠️ Disclaimer
JOBSHIELD is an academic data analytics project. The dashboard presents patterns found within the dataset and does not guarantee that any individual job posting is fraudulent. Users should independently verify job offers and recruiters before sharing personal information or making payments.
